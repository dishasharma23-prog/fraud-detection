Card Fraud Detection

A LightGBM model trained on the IEEE-CIS dataset of real e-commerce card transactions. It was trained on the oldest transactions and tested only on the newest ones, the way a fraud model is used in practice.

How it works. Each transaction has about 430 columns: amount, product, card details, billing region, email domains, device, plus count, time-gap and match features from Vesta, the company that released the data. The model returns a fraud probability. A transaction is flagged when that probability passes a threshold chosen so that only 1% of legitimate transactions get flagged, set on a validation month the test never saw. The factors come from SHAP values: red pushed the score up, green pulled it down.
